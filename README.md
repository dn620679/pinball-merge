# 핀볼 머지 (Pinball Merge)

`index.html`을 브라우저에서 바로 열면 실행됩니다. 서버, 빌드, 외부 라이브러리가 필요 없습니다.

- 조작: 구매 ×1 / ×10 / MAX, 자동 병합 ON/OFF, 카드 뽑기, 강화(장치 해금·발사기·구매 티어), 도감(돌파)
- 단축키: `1` 구매, `2` ×10, `m` 병합 토글, `` ` `` 또는 F9 디버그 패널 (설정 하단 버전 글자 5회 탭으로도 열림, `?debug` 쿼리)
- 테스트: `node tools/test.js` (필수 시나리오 + 물리 통계), `node tools/econ.js 3` (3시간 진행 속도 시뮬레이션)
- 밸런스 값: `js/config.js` (디버그 패널에서 실시간 변경 가능)
